# NDM_LAMMPS
## Principles
NDM can be linked with a lammps library on compilation. lammps is used solely to get the potential energy, forces and stress. All the rest is dealt with with NDM.  
The run needs additional files to make LAMMPS work properly, see below.  
NDM space paralelization is replaced by LAMMPS intrnal parallelization. All other parallelization levels can be activated.

##NDM Input files
###din file
**ipotentiel=-10** lammps potential without charge or **ipotential=-11** lammps potential with charge.  
This choice affects the format of NDM generated atomic configuration files.  
**units_lammps='metal'** lammps unit system of te potential must be specified.
###simple.potin
A basic NDM potential file must be provided, e.g. :  
 3 ! nb of types  
11.0 cutoff (not reaqly needed but ensures consistency between NDM cells and LAMMPS cutoff)  
15.9994 8.0 'O ' -1.1104   ! mass, atomic number, symbol charge  
238.03  92.0 'U'  2.2208  
131.4  54.0 'Xe'  0

## LAMPMS input files
**For a simple run with a single box:  **
###in.lammps   
A minimalist lammps input file  
####example 1:  
units		metal  
atom_style      atomic  
atom_modify     map array  
box tilt large  
**read_data        conf.lmp**
mass       1  55.84500  
pair_style	eam/alloy  
pair_coeff      * *        M07_eam.fs Fe  
####example2
box tilt large  
log             log_XeUO2_lammps  
units           metal  
atom_style      charge  
atom_modify     map array  
dimension       3  
boundary        p p p  
**read_data       conf.lmp**  
variable O equal 1  
variable U equal 2  
variable Xe equal 3  
set type $O charge -1.1104  
set type ${U} charge 2.2208  
set type ${Xe} charge 0
mass            1 16.00  
mass            2 238.03  
mass            3 131.4  
pair_style hybrid/overlay eam/alloy snap table linear 1000 pppm  
pair_coeff * * eam/alloy potential/CeThUNpPuAmCmO.eam.alloy O U NULL  
pair_coeff * * snap potential/snap_pbesol.coeffs potential/snap_pbesol.params O U NULL  
pair_coeff   ${O}  ${Xe}  table potential/CRG_gas_potentials.lmptab Xe-O 11  
pair_coeff   ${U}  ${Xe}  table potential/CRG_gas_potentials.lmptab Xe-U 11  
pair_coeff   ${Xe} ${Xe} table potential/CRG_gas_potentials.lmptab Xe-Xe 11  

###atomic configuration file conf.lmp  
The atomic configuration file (conf.lmp) is generated by NDM. No need to prepare it.  

**For NEB calculations**, the same files are erquired as in the basic case (as all images have the same number of atoms).
