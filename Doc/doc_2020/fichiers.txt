fichiers d'entrées  (voir description détaillée ci-dessous)
name.in : contient le NOM du job
NOM.din : options de dynamique
NOM.GIN ou NOM.CIN : descrition de la boite, positions et types des atomes
'potentiel'.potin : description du potentiel

******** fichier NOM.din *******
exemple :*-----------------

 &input
	igen=0 !(*) =0 lecture .gin; =1 lecture .cin/cout 
	imm=7000 !(*) nombre max d'atomes (taille des tableaux)
	dmtype=15 !(*) type de DM (4= Velocity Verlet; 3= GC ; 2=trempe rapide, 1= verlet std, etc.
	tinit=400! (*) si .gin	! temperature initiale

	itmax=3 ! nombre max d'itarations
	itetemp=1 ! période sortie des température et énergies 
	itesigma ! période sortie des pressions 
 &end
fin ex :*-------




c'est le fichier qui donne les options du calculs de dynamique moleculaire.
Il est constitue d'une "name list". Une name list est un ensemble de donnees
 lues par le code.
L'ordre de ces donnes n'est pas important, une donnee peut apparaitre ou non
dans la liste.
Pour la plupart des donnes des valeurs par defauts sont incluses dans le
programme.
Cependant certaines donnes DOIVENT etre precisees.
exemples
Calcul DM NVE
&input
	ipotentiel=10 !****   type de potentiel
	imm=2000  !****  taille des tableaux sur les atomes
	igen=0   !**** type de structure 0=.gin 1=.cin
	dmtype=1   ! **** verlet standard ; 4 = velocity 3: GC : 4 =trempe voir "variablesddans.din	
	tinit=600  ! temperature d'initialisation (complétés par lvpread =vitesses lues)
	itmax=100  ! *** nombre de pas
	itetemp=1  ! fréquence d'écriture des températures
	lEev=.true. ! énergies en eV (et non cgs)
        lPkbar=.true. ! pressions en kbar
	itesigma=1  ! fréquence d'écriture des contraintes
	iterasmol=10 ! écriture des positions dans des fichiers    
ivisu=1 ! format de sortie dans rasmol.f90 : ivisu=1=.mol, ivisu=2=vsim mal code supprime, ivisu=3=xred , ivisu=4 CFG a préférer à itecfg ; ivisu=5 .newgin

	lperiod=.true. ! poistions réduites entre 0 et 1
	ltabvois=.false. ! calcul des forces par la table des voisins (pas para) fréquence de calcul itetabvois=10
 &end

         0.681783702850230D-03        -0.261109882001193D-01        -0.191490264450510D+02
