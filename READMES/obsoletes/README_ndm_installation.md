## NDM installation on local user host

* NDM-INTEL installation needs **prerequisites**
  - oneAPI for intel compilers (2022.0.1)
  - oneAPI MKL
  - oneAPI intelmpi

* NDM-GNU installation needs **prerequisites**
  - GNU compilers (min V9)
  - link to MKL oneAPI intel-compiled, libraries gf (gnu), tricky.
  - openmpi user-compiled, or system, gnu-compiled

* NDM-MIX installation needs **prerequisites**
  - oneAPI for intel compilers (2022.0.1)
  - oneAPI MKL intel-compiled
  - openmpi user-compiled, or system, compatible with intel compilers (3.1.6 or 4.1.2)

**WARNING**
- **Marinica prefers NDM-MIX**


### oneAPI installation

INSTALL oneAPI on linux from scratch
- Without sudo root
- On user local disk directory

See [README_oneAPI_installation.md](README_oneAPI_installation.md)

Before oneAPI installation see
[www.intel.com, base-toolkit-download](https://www.intel.com/content/www/us/en/developer/tools/oneapi/base-toolkit-download.html?operatingsystem=linux&distributions=webdownload&options=online)

After oneAPI installation see
[www.intel.com, get-started](https://www.intel.com/content/www/us/en/develop/documentation/get-started-with-intel-oneapi-base-linux/top.html)


### openmpi installation

INSTALL and compile openmpi on linux from scratch
- Without sudo root
- On user local disk directory

See [README_openmpi_installation.md](README_openmpi_installation.md)

### NDM-INTEL installation

As oneAPI use, you have to initialize oneAPI environment,

See [README_oneAPI_setvars_modules.md](tips/README_oneAPI_setvars_modules.md)

INSTALL and compile NDM on linux from scratch with intel oneAPI compilers
- Without sudo root
- On user local disk directory
- Using intel oneAPI MKL
- Using intelmpi

```
# Follow 'GENERAL setenv prerequisites'

# init environment to use oneAPI compilers (if not done yet)
# see tips/README_oneAPI_setvars_modules.md
# do not forget with mpi intel module
export CONFIG_SETVARS=${NDM_ROODIR}/config_setvars_oneapi_with_mpi.tmp

cat <<EOT > ${CONFIG_SETVARS}
default=exclude
compiler=latest
mkl=latest
mpi=latest
EOT
cat ${CONFIG_SETVARS} # to verify

source ${NDM_OAP_INSDIR}/setvars.sh --config=${CONFIG_SETVARS}

f_setenv_ndm
f_compile_ndm_intel
f_explore_ndm
f_ctest_ndm
conda env list
conda activate py3jupy
f_python_tests_ndm
```

#### Problem gnu

Sometimes it is tricky to use code gnu-compiled
linked by mkl intel or gf libraries

see https://users.open-mpi.narkive.com/ZPgZF9Ui/ompi-undefined-reference-to-intel-sse2-strlen

```
this error typically occurs when different compiler suites used for compiling
C/C++ mixed source code.
Please add CXX=icpc to your configure command in order to use a single compiler
suite (=Intel) for compiling Open MPI. Otherwise, CXX is set to the default
compiler (=g++) which isn't suitable for linking objects generated by the
Intel compiler.
```

### NDM-MIX installation

INSTALL and compile NDM on linux from scratch with intel compilers
- Without sudo root
- On user local disk directory
- Using intel oneAPI MKL
- Using openmpi compiled with intel


```
# Follow 'GENERAL setenv prerequisites'

# init environment to use oneAPI compilers (if not done yet)
# see tips/README_oneAPI_setvars_modules.md
# do not forget DO NOT use mpi intel module
export CONFIG_SETVARS=${NDM_ROODIR}/config_setvars_oneapi.tmp
source ${NDM_OAP_INSDIR}/setvars.sh --config=${CONFIG_SETVARS}

export MKLROOT=${NDM_OAP_ROODIR}/oneapi/mkl/2022.0.1
export MKL_ROOT=${MKLROOT}

envs -p NDM_MPI_ # example is246206
  NDM_MPI_INSDIR                     = /export/home/catA/wambeke/NDM/mpi/install_412_intel
  NDM_MPI_INSDIR_ORIG                = /export/home/catA/wambeke/NDM/mpi/install_412
  NDM_MPI_ROODIR                     = /export/home/catA/wambeke/NDM/mpi
  NDM_MPI_SETENV                     = ON
  NDM_MPI_SRCDIR                     = /export/home/catA/wambeke/NDM/mpi/openmpi-4.1.2

f_setenv_ndm_wambeke # user have to make his own setenv
f_compile_ndm_mix
f_compile_ndm

# finalize PATH etc for execution
f_help_ctest_ndm

# and so on set LD_LIBRARY_PATH
export LD_LIBRARY_PATH_ORIG=${LD_LIBRARY_PATH}

export LD_LIBRARY_PATH=${MKL_ROOT}/lib/intel64:${NDM_MPI_INSDIR}/lib:${LD_LIBRARY_PATH}
export LD_LIBRARY_PATH=${NDM_OAP_INSDIR}/itac/2021.5.0/bin/rtlib:${LD_LIBRARY_PATH}
export LD_LIBRARY_PATH=${NDM_OAP_INSDIR}/compiler/2022.0.1/linux/compiler/lib/intel64_lin:${LD_LIBRARY_PATH}

# export LD_LIBRARY_PATH=${NDM_OAP_ROODIR}/oneapi/mkl/2022.0.1/lib/intel64:${NDM_MPI_INSDIR}/lib:${LD_LIBRARY_PATH}
# export LD_LIBRARY_PATH=${NDM_OAP_ROODIR}/oneapi/itac/2021.5.0/bin/rtlib:${LD_LIBRARY_PATH}
# export LD_LIBRARY_PATH=${NDM_OAP_ROODIR}/oneapi/compiler/2022.0.1/linux/compiler/lib/intel64_lin:${LD_LIBRARY_PATH}

# and so on set mpirun PATH
export PATH_ORIG=${PATH}
export PATH=${NDM_MPI_INSDIR}/bin:${PATH}

envs -e LD_LIBRARY_PATH
envs -e PATH

f_explore_ndm
f_ctest_ndm

export NDMPY_ROOT_DIR=${NDM_SRCDIR}
f_python_tests_ndm
```

## NDM installation on IRENE AMD

Current directories NDM installation-compilation (from wambeke policy) is:

```
# may be ${CCCWORKDIR} is /ccc/work/cont002/den/${USER}
export NDM_ROODIR=${CCCWORKDIR}/NDM
tree -d -L 2 ${CCCWORKDIR}
/ccc/work/cont002/den/vanwambc
└── NDM
    ├── NDM
    ├── ndm_build_intel
    ├── ndm_install_intel
    └── ndm_tesdir
```

- NDM is git NDM directory with sources
  from https://codev-tuleap.intra.cea.fr/plugins/git/ndm/NDM.git
- ndm_build_* are directories for CMAKE build(s)
  (ndm_build_gnu, ndm_build_intel, ndm_build_mix), as concurrency build(s) for benchmarks.
- ndm_install_* are directores for compiled ndm-code *installation* (as `make install` actions),
  obvioulsy it could be at others places, this choice is a *user conveniency*.
- ndm_tesdir is directory of integration tests (from Marinica `small_tests`)
  (see also bash function `f_python_tests_ndm` in
  [compile_ndm.bash](../scripts/compile_ndm.bash)
