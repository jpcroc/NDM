.. _iraMainWidget:

Iradina GUI main widget
------------------------

From this main widget named *Iradina GUI* users can:

#. Prepare Iradina code data.
#. Run Iradina code.
#. Plot curves from result files of Iradina code runs.


.. image:: images/iradinaMainWidget1.png
   :scale: 80 %
   :align: center


.. _iraMainWidgetToolbar:

Main widget toolbar
.....................


.. image:: images/iradinaMainWidgetToolbar1n.png
   :align: center

This toolbar contains icons related to actions, from left to right:

#. New Iradina data. Create iradina case from scratch
#. Load Iradina data. Load case from previously saved case in a file Xml.
#. Save Iradina data. Save current iradina case in a file Xml.
#. Launch Iradina calculus. Launch Iradina code on current iradina case.
#. Refresh IradinaObjects tree view.
#. Clear Iradina data model, remove Iradina data tree (in IradinaObject widget).
#. Iradina GUI help. Display this current documentation in a browser (html mode).
#. Iradina code help. Display Iradina code manual in a browser (pdf mode).
