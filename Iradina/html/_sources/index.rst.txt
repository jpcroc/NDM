Iradina GUI
************

.. image:: images/icon_about_IradinaGUI.png
   :align: center

.. warning:: #. This documentation is under construction.
             #. Find a *pdf* version of this documentation `here <IradinaGuiPdf_>`_ [1]_.
             #. Find *Iradina code* manual `here <IradinaManualPdf_>`_ [2]_.

The iradinaGUI code is a GUI_ (Graphical User Interface)
used to perform operations with `Iradina code <IradinaPresentationPdf_>`_.

This GUI code is a set of Python3_ scripts files.
