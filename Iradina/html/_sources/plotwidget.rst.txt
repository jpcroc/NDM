.. _iraPlotWidget:

Plot widget
--------------------------

This widget is to explore, modify and make plots from data.
It appears when users activate **matplotlib plot** in :ref:`iraFilesNamesMenu`.

It uses some important Python packages:

#.  PANDAS_ (Python Data Analysis Library) to read and store data in memory.
#.  MATPLOTLIB_ (Python 2D plotting library) to plot curves.

.. warning:: Data are read from CSV_ formated files.
             Note that result files of Iradina code use whitespace/tabulation
             for separator character, *not comma*, for readability.


.. image:: images/iradinaPlotWidgetPlots1.png
   :scale: 80 %
   :align: center

There are four main widgets (from up to down, left to right):

#. Plots toolbar widget
#. Infos tab widget
#. Contents tab widget
#. Plots tab widget


.. _iraPlotToolbarWidget:

Plot toolbar widget
:::::::::::::::::::::::::::::::

.. image:: images/iradinaToolbarWidgetPlots1n.png
   :align: center

This menu contains some buttons, as actions, which are, from left to right:

#. Read a new data set from file, CSV_ formatted.
#. Plot curve y=f(x). 2 columns (x,y) selected.
#. Plot 2 curves (y1,y2)=f(x), two distinct Y-axis. 3 columns (x,y1,y2) selected.
#. Plot n curves y1,...yn=f(x), one Y-axis, (n+1) columns (x,y1,...yn) selected.
#. Plot n *distinct* curves y1,...yn=f(x), (n+1) columns (x,y1,...yn) selected.
#. Plot histogram, one columns selected, (automatic number of intervals).
#. Execute PANDAS_ expressions, modification **on the fly** of *Contents tab widget*.
#. Initialize data **ellipse** in *Contents tab widget* (as a *newbie example*),
   plot the ellipse.

With this toolbar, user may process:

#. Select one, or more columns in *Contents tab widget*,
   then call plot of curve(s) using plot buttons of this plot toolbar.
   A MATPLOTLIB plot is displayed in *Plots tab widget*.
   See :ref:`ExampleUserPlot`.
#. Create, remove, calculate new(s) colums of data in *Contents tab widget*.
   See :ref:`ExamplePandasExpression`.
#. Filter, sort etc. lines of data in *Contents tab widget*,
   that means also get (and trace) a subset of *Contents tab widget*.

Contents tab widget

.. image:: images/iradinaContentsTabWidgetPlots1.png

This widget displays current data, allowing some *elementary*
modifications (see your appropriate spreadsheet for more functionalities
(Excel, or else).


Plots tab widget
:::::::::::::::::::::::::::::::

.. image:: images/iradinaPlotsTabWidgetPlots1.png

This widget displays current plot, as an instance of matplotlib_ *figure*.

::::::::::::::::::::::::::::::::::::::::::::::

`navigation toolbar MATPLOTLIB <NavToolPlt_>`_.

.. _ExamplePandasExpression:

Example of user PANDAS expression
::::::::::::::::::::::::::::::::::::::::::::::

User may modify data of :ref:`iraContentsTabWidget`,
Clicking on menu actions button *Execute PANDAS expressions* of
:ref:`iraPlotToolbarWidget`.

.. image:: images/iradinaExecutePandasExpression0.png
   :align: center

A dialog box appears *set your pandas expression*.
An expression is an python affectation expression *'df = something'*,
where 'df' *is* a pandas dataframe instance displayed
in :ref:`iraContentsTabWidget`.

.. image:: images/iradinaExecutePandasExpression2.png
   :scale: 80 %
   :align: center

Scrolling, there are some examples of PANDAS_ dataframe expressions,
(read the documentation, sometimes it is **not trivial**).

.. image:: images/iradinaExecutePandasExpression3.png
   :scale: 80 %
   :align: center

Users have to type their own expression, and confirm (OK).
Do not worry, in case of error(s) in expression, an error dialog box appears.

.. image:: images/iradinaExecutePandasExpression5.png
   :scale: 80 %
   :align: center
