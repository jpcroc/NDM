Installation Notes for windows (file iradina*.7z)

The GUI does not work on 32 bit machines.

0/Create a directory IRADINAGUI_WORKDIR in C:\Users\YOUR_ACCOUNT

1/put the iradina_1811129.7z file in C:\Users\Public (!not in your directory)
2/unzip and extract the file
3/ the iradina GUI launch file is C:\Users\Public\iradina\iradinaGUI\laucnhIradinaGui Double click on this file should work directly. You may create an alias for this file to put on your desktop or where you want. 


TESTS ARE AVAILABLE IN iradinaGUI\examples

In the GUI :
The blue button with a question mark launchs the html help for the GUI and CEA installation. Please read it.
The green button with the question mark opens the pdf help of the iradina code in the original version by C. Borschel and C. Ronning.
Contextual help pops up when the mouse is placed over a variable or a button.
Some menus are accesssible with a right click.
